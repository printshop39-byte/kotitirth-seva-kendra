# नित्यसेवा पोथी — स्रोत फोटो

येथे पोथीच्या **स्पष्ट फोटो / स्कॅन** ठेवा. OCRवर पूर्ण विश्वास ठेवू नका.

## नामांकन

```
pNNN-title.jpg
```

उदाहरण:

- `p005-parjanya-sukta.jpg`
- `p009-ramraksha.jpg`

## पडताळणी workflow

1. फोटो टाका  
2. `data/*.json` मध्ये मजकूर टाइप करा (`status: "draft"`)  
3. संस्कृत जाणणाऱ्या सेवेकऱ्याकडून अक्षरशः तपासा  
4. तपासणी झाल्यावरच `status: "verified"` + `verifiedBy` + `verifiedDate`  
5. GitHub commit इतिहास जतन राहतो  

तपासणी चिन्हे: `ं` `ँ` `ः` `ऋ` `श/ष/स` `ण/न` `ळ/ल` `।` `॥` `ऽ`
