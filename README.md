# श्री स्वामी समर्थ सेवा केंद्र – कोटितीर्थ, कोल्हापूर

QR स्कॅन केल्यावर उघडणारे मोबाईल-फ्रेंडली माहिती पेज. फक्त HTML — सर्व्हर, डेटाबेस, खर्च काहीही नाही.

| फाईल | काम |
|---|---|
| `index.html` | मुख्य पेज (QR स्कॅन केल्यावर हेच दिसते) |
| `qr.html` | QR तयार करून SVG / PNG / फलक PDF घेण्यासाठी |

## १. GitHub वर टाका (१० मिनिटे)

रेपो तयार आहे: `printshop39-byte/kotitirth-seva-kendra` — फाईल्सही आत आहेत.

1. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`, folder `/ (root)` → Save
2. २ मिनिटांनी लिंक तयार:
   `https://printshop39-byte.github.io/kotitirth-seva-kendra/`

## २. QR तयार करा

- वरची लिंक + `qr.html` उघडा
- लिंक चिकटवा → **SVG डाउनलोड** (फ्लेक्स/बोर्डसाठी) किंवा **फलक PDF प्रिंट करा**
- प्रिंटआधी एकदा स्वतः स्कॅन करून खात्री करा

## ३. माहिती बदलायची असेल तर

`index.html` मध्ये खाली `const KENDRA = {` हा भाग आहे — **फक्त तेवढाच बदला**:

```js
sevekari : "श्री सुनील तावरे",
phone    : "+91XXXXXXXXXX",     // <-- खरा नंबर टाका
mapQuery : "कोटितीर्थ तलाव, कोल्हापूर",

seva: [
  { t:"08:00", name:"भूपाळी व आरती",   sub:"दिवसाची सुरुवात" },
  { t:"10:30", name:"आरती",             sub:"मध्यान्ह सेवा" },
  { t:"18:00", name:"आरती व नित्यसेवा", sub:"सायंकाळची सेवा" }
]
```

वेळ नेहमी **२४ तासांच्या** फॉरमॅटमध्ये (`18:00` = सायं. ६). पेज आपोआप मराठी अंकात दाखवते.

> **महत्त्वाचे:** नंबर टाकेपर्यंत फोन/WhatsApp बटणांवर “नंबर टाका” दिसेल.

## आजचे पंचांग (Marathi Panchang)

“आज” पानावर नित्य सेवा वेळापत्रकाच्या वर **आजचे पंचांग** दिसते — वार, तारीख,
मराठी मास, पक्ष, तिथी (+ शेवटची वेळ व बदलल्यास पुढील तिथी), नक्षत्र, योग, करण,
सूर्योदय/अस्त, चंद्रोदय/अस्त, चंद्रकला व सण/विशेष दिवस.

**पूर्णतः मोफत — कोणतेही API, key, सर्व्हर किंवा खर्च नाही. सर्व गणना ब्राउझरमध्येच
(offline सुद्धा) होते.**

### गणना इंजिन (calculation engine)

- **[astronomy-engine](https://github.com/cosinekitty/astronomy) (Don Cross)** — फक्त
  खगोलीय स्थान/उदयास्तासाठी. `assets/vendor/astronomy.browser.min.js` मध्ये vendored.
- **का निवडले:** MIT परवाना, शून्य dependency, ब्राउझरमध्ये थेट चालते (build लागत नाही),
  उच्च अचूकता, कोणताही remote API/key नाही → GitHub Pages व offline साठी योग्य.
- **परवाना (license):** MIT (`assets/vendor/astronomy-engine.LICENSE.txt`). आपले पंचांग-कोड
  याच रेपोचा भाग.
- तिथी/नक्षत्र/योग/करण/मास/चंद्रकला व सण-नियम `assets/panchang/engine.js` व
  `festival-rules.js` मध्ये स्वतः लिहिले आहेत.

### स्थान व वेळ

- **स्थान:** कोल्हापूर — `assets/panchang/config.js` मध्ये `latitude/longitude` ही एकच जागा
  बदलली की पूर्ण पंचांग बदलते. (भाविकाला GPS विचारले जात नाही.)
- **वेळक्षेत्र:** `Asia/Kolkata` (स्थिर +5:30).
- **अयनांश:** लाहिरी (चित्रपक्ष), रेखीय मॉडेल.

### मराठी mapping कसे चालते

सर्व मराठी नावे व अंक/वेळ-स्वरूप `assets/panchang/marathi.js` मध्ये एकत्र आहेत —
गणनेच्या कोडात मराठी मजकूर विखुरलेला नाही; कोड फक्त क्रमांक देतो, नाव इथून मिळते.

### सण कसे ठरतात

तीन स्तर वेगळे (`festival-rules.js` व `assets/data/local-events.js`):

1. **खगोलीय-गणित सण** — मास + तिथी + योग्य कालखंड. प्रत्येक सणाचा योग्य काल वापरला:
   उदय (पौर्णिमा/एकादशी), मध्यान्ह (गणेश चतुर्थी, रामनवमी), अपराह्न (दसरा),
   प्रदोष (लक्ष्मीपूजन), निशिथ (महाशिवरात्री).
2. **स्थिर ग्रेगोरियन दिवस** — उदा. स्वातंत्र्य दिन, प्रजासत्ताक दिन.
3. **स्थानिक केंद्र कार्यक्रम** — `assets/data/local-events.js`.

मोठे सण सौम्य मोडलने (एका दिवसातून एकदा; `localStorage` मध्ये तारीख+सण नुसार नोंद),
छोटी निरीक्षणे (एकादशी, प्रदोष, संकष्टी, अमावस्या, पौर्णिमा) badge ने दाखवली जातात.

### स्थानिक कार्यक्रम कसे जोडावेत

`assets/data/local-events.js` मध्ये नोंद जोडा (मुख्य पंचांग कोडाला हात न लावता):

```js
{ date:"2026-08-15", titleMr:"कार्यक्रम", descMr:"माहिती",
  type:"event", priority:5, showPopup:true,
  ctaText:"आजची सेवा पहा", ctaTarget:"seva" }
```

### चंद्रकला (moon)

`assets/panchang/moon.js` — आजच्या **प्रत्यक्ष** प्रकाशित अंशानुसार SVG चंद्र
(वाढता → उजवीकडे, घटता → डावीकडे प्रकाश). खोटी लूप-ॲनिमेशन नाही; लोडवर सौम्य रिव्हील,
आणि `prefers-reduced-motion` असल्यास ॲनिमेशनशिवाय अचूक स्थिती.

### ज्ञात मर्यादा (known limitations)

- तिथी **सूर्योदयाधारित**. काही सण संप्रदायभेदाने ±१ दिवस बदलू शकतात (उदा. जन्माष्टमीचा
  निशिथ-नियम); जिथे अचूकता खात्रीशीर नाही तिथे मूल्य **दाखवले जात नाही**.
- **एकादशी 'क्षय'** (सूर्योदय न स्पर्शणारी) वर्षी ती दाखवली जात नाही — चुकीचा दिवस
  दाखवण्यापेक्षा वगळणे (उदा. कार्तिकी एकादशी २०२६).
- लाहिरी अयनांश रेखीय मॉडेल — नक्षत्र/योग सीमेजवळ क्वचित सीमारेषेवर फरक शक्य.
- मास = **अमांत** (महाराष्ट्र) पद्धत; अधिक मासात लूनर-सण नियम वगळले जातात.
- गणना अयशस्वी झाल्यास “आजचे पंचांग सध्या उपलब्ध नाही.” दिसते; उर्वरित साइट (जपमाळा)
  चालूच राहते. **चुकीचे मूल्य कधीही दाखवले जात नाही.**

### तारखा तपासणे (testing)

- कोणताही दिवस पाहण्यासाठी: `?panchang-date=YYYY-MM-DD`
  (उदा. `index.html?panchang-date=2026-09-14` = गणेश चतुर्थी).
- विकसक पडताळणी पान: `assets/panchang/validation.html` — अनेक तारखांचे तपशील
  (सूर्योदय, सूर्य/चंद्र रेखांश, तिथी, पक्ष, नक्षत्र, चंद्रकला, सण-ध्वज) व २०२६ सणांची
  प्रकाशित तारखांशी पडताळणी.

