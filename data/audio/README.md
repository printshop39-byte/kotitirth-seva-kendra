# आरती/मंत्रांच्या MP3 फाईल्स — इथे टाका

साईटवरचं "🔊 ऐका" बटण आधी इथे संबंधित नावाची MP3 फाईल शोधतं. फाईल सापडली तर
तीच वाजते (खरा आवाज — ऐकायला आणि pause/resume/seek करायला उत्तम). फाईल
सापडली नाही तर आपोआप, कोणताही एरर न दाखवता, ब्राउझरच्या मराठी आवाजाकडे
(TTS) वळतं — त्यामुळे फाईल अजून नसली तरी साईट नेहमीसारखीच चालते.

## कसं वापरायचं

1. आरती/पाठ/मंत्र म्हणून रेकॉर्ड करा (फोनवरही चालेल — साधा आवाज पुरेसा).
2. खालच्या तक्त्यातलं बरोबर नाव देऊन `.mp3` म्हणून सेव्ह करा.
3. ही फाईल याच फोल्डरमध्ये (`data/audio/`) टाका, GitHub वर push करा.
4. पुढच्या वेळी कोणी "ऐका" दाबेल तेव्हा तुमचा आवाज वाजेल — कोडमध्ये
   काहीही बदलायची गरज नाही.
